Privacy Policy

Last updated: September 2026

1. Anonymous Usage Analytics

Dark Light sends anonymous app and extension startup events, plus one daily check-in while the host app is running. These events contain only locale, platform, operating-system, app version, and debug-status information. They never include personal information, browsing history, page content, screen contents, website rules, or a persistent device identifier.

2. Permissions

Browser permissions let Dark Light store website appearance rules and apply them locally. App Theme Control on macOS uses Screen Recording permission only to transform selected apps without automatic light and dark themes; Dark Light does not record, save, or upload screen contents.

3. Third-Party Services

We use Aptabase to process these anonymous usage events. Aptabase does not receive browsing or screen content, and Dark Light does not use advertising networks.

4. Contact

If you have any questions or concerns regarding this privacy policy, please contact us via our GitHub repository.
